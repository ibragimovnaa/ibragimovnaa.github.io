PROFILE PHOTO:
Place your JPG image in this same folder and name it exactly photo.jpg.
The page crops it into a circle automatically.

NETWORK DETECTIVE:
- The ISP / ASN label is looked up from the public IP-information service ipwho.is.
  The IP address itself is never inserted into the page.
- A normal browser page cannot reliably discover the router manufacturer.
- Browser JavaScript cannot run traceroute to inha.uz, so hop count is marked unavailable
  rather than showing an invented value.
- Do not add IP or MAC addresses to the public page.

To preview:
1. Keep all four files in the same folder.
2. Add your photo as photo.jpg.
3. Open index.html in a browser. Internet access is needed for the ISP lookup.
4. Test the sticky header, mobile menu, and Dark mode button.
